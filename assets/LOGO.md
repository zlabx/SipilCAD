# Logo

`logo.svg` is the SipilCAD icon (a two-layer shape with a "CAD" label) and `logo-small.svg` its label-free variant, which the
web page uses as favicon because a favicon is shown at 16-32 px, where the label is unreadable. The dialogs and the window
icon use `logo.svg`.

Both files come from the SipilStock icon set. The three letters of the label are outlines of **PT Sans Bold** (Copyright (c)
2009 ParaType Ltd., SIL Open Font License 1.1); no font is embedded in the SVG. The licence text is `web/pt-sans/OFL-PTSans.txt`
in this tree (served next to the app as `OFL-PTSans.txt`, linked as "Font" in the About dialog).

The splash screen of the web page (`web-app.html`) is set in PT Sans too: `web/pt-sans/PT_Sans-Web-Regular.ttf` and
`PT_Sans-Web-Bold.ttf`, used unmodified because the licence reserves the name "PT Sans".
